Flock Energy Take-Home Assignment: Non-Intrusive Load Monitoring (NILM) & Appliance Disaggregation1. What You BuiltAn end-to-end Python-based data engineering, exploratory analysis, and Non-Intrusive Load Monitoring (NILM) disaggregation pipeline using the official REFIT smart-meter dataset at 1-minute resolution.The project is structured across four clean, executable Jupyter notebooks and four submission documentation files:01_data_cleaning.ipynb: Handles raw data cleaning, chronological indexing, deduplication, linear gap interpolation ($\le 15$ min), and long outage flagging ($> 15$ min).02_washing_machine_eda.ipynb: Conducts washing-machine usage analysis across 4 target households (Houses 1, 2, 3, and 5), defines active wash cycles, and generates mandatory visual traces (24-hour aggregate, single-cycle detail, and cross-household comparisons).03_nilm_model.ipynb: Extracts rolling temporal features, implements a cross-household train/test split, trains a Random Forest disaggregation model against an "Always-Off" baseline, evaluates metrics (MAE, RMSE, On/Off $F_1$-score), and performs failure case analysis.04_practical_implications.ipynb: Explores utility-facing customer opportunities (A/B testing for peak load shifting), technical/geographical limitations (UK to India applicability), and the impact of coarse (15/30-min) smart meter data.Documentation: README.md, DATA.md, RESULTS.md, and Recommendation.md.2. AssumptionsAppliance Assignment: Washing-machine channels follow official REFIT metadata mappings (House1: Appliance1, House2: Appliance2, House3: Appliance6, House5: Appliance1).Power Thresholds: Power draw below $20\text{ W}$ represents idle/standby power, whereas power above $20\text{ W}$ represents active washing/heating/spinning phases.Temporal Consistency: 1-minute aggregate power logs provide sufficient granularity to capture high-power resistive heating spikes ($> 2000\text{ W}$) and motor rotation pulses.4. Preprocessing DecisionsDeduplication & Indexing: Timestamps were parsed as UTC DatetimeIndex, sorted chronologically, and duplicate timestamps were removed.Gap Handling Rules:Gaps $\le 15\text{ minutes}$: Imputed using linear interpolation to preserve continuous sequence dynamics for feature engineering.Gaps $> 15\text{ minutes}$: Explicitly flagged as grid/system outages and excluded from training to prevent artificial flatlining.Active Cycle Definition: An active washing-machine cycle is defined as power $> 20\text{ W}$ sustained for $\ge 15\text{ continuous minutes}$, allowing for momentary pauses $\le 5\text{ minutes}$ (e.g., rinse/soak transitions).5. Validation DesignLeakage Prevention (Cross-Household Split): Randomly splitting time-steps within the same house causes severe data leakage due to autocorrelation between adjacent minutes. To test true out-of-sample generalization across unseen behaviors:Training Set: Houses 1, 2, and 3 (~30% stratified sample per house to optimize memory).Testing Set: House 5 (unseen test household).Evaluation Metrics:MAE & RMSE: Quantify continuous power estimation accuracy in Watts.On/Off $F_1$-Score: Measures classification accuracy in detecting whether the washing machine is actively operating ($> 20\text{ W}$).Baseline Comparison: Models were benchmarked against a naive "Always-Off" baseline ($0\text{ W}$ constant prediction).6. Trade-OffsSubsampling vs. Training Size: Full multi-year minute-level training data across 3 households generated millions of feature rows, causing Google Colab kernel crashes. A 30% sample was used to guarantee runtime stability while preserving feature distribution integrity.Model Complexity: Selected a lightweight Random Forest regressor ($20$ trees, max depth $8$) over deep sequence models (e.g., Seq2Point) to ensure reproducible, fast execution within free-tier Colab RAM limits without sacrificing interpretability.7. AI Tools UsedGemini 3 Flash / LLM Assistants: Used as a collaborative coding and writing assistant for rapid prototyping, structuring clean visual plots, diagnosing pandas/Colab runtime warnings, and drafting structured markdown submission documentation.8. Possible ImprovementsDeep Learning Architectures: Implement Sequence-to-Point (Seq2Point) or Bidirectional LSTM neural networks with temporal attention mechanisms to better model multi-phase wash cycles.Multi-Appliance Disaggregation: Expand the model into a multi-output regressor to simultaneously disaggregate dishwashers, electric space heaters, and kettles.Feature Enrichment: Include rolling frequency-domain transform features (FFT) or reactive power metrics if higher-frequency or multi-channel smart meters are available.
